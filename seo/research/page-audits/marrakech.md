## Diagnosis

**Every one of this page's target tourism keywords is held by a blog post ranking ~27 positions
higher.** `/blog/site-web-hotel-riad-marrakech` sits at 2.12–6.24 on the same queries where this
page sits at 29–31. See [`_cannibalisation.md`](_cannibalisation.md) cluster 3.

This is not a case where the city page is being held down *by* the blog post — Google has simply
judged the blog post far more relevant for riad/hotel website queries. The blog post is a focused
article on exactly that topic; the city page is a general Marrakech services page that mentions
riads.

**The page's one genuine win is `create website guesthouse morocco` at 14.64** — its best position
by 12 places, on a query the blog post does not hold at all. That is the thread worth pulling.

The English-language demand is real and confirmed: `web design riad marrakech english`, `morocco
riad website builder`, `riad website design morocco`, `create website guesthouse morocco` are all
English queries, matching the §6 requirement for English content on this page. The demand exists;
the page is just not the one Google picks.

**Losing 2 clicks to 0 while position improved** is a small-numbers effect (2 clicks is noise), but
it does mean this page currently contributes nothing.

## Actions

1. **Do not try to outrank the blog post on riad terms.** It holds positions 2–3. Displacing it
   would trade a top-3 ranking for a speculative one.
2. **Retarget on what the blog post does not own** — `create website guesthouse morocco` (14.64),
   guesthouse/maison d'hôtes phrasing, and the booking-system angle (`site réservation riad maroc`,
   §5.2) which appears nowhere in the current query data for either page. That is unclaimed ground.
3. **Strengthen the English section.** Four of the six top queries are English. §6 already requires
   this; the data says it is under-delivered.
4. **Link the blog post to this page** with a keyword-rich anchor so its position-2 traffic flows
   here. That converts the cannibalisation into a funnel.
5. **Solve the blog post's CTR problem first** — it has 114 impressions at positions 2–6 earning
   zero clicks. Fixing that is worth more than anything on this page. See
   [`blog-site-web-hotel-riad-marrakech.md`](blog-site-web-hotel-riad-marrakech.md).
6. **Do not change the slug** — five active Ads keywords (§10).
