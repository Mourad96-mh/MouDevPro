## Diagnosis

**Second-worst offender in cannibalisation cluster 1.** It ranks 31.96 for `développeur web
freelance maroc` — better than the money page (36.78) — on 45 impressions, its largest query by far.
Along with `/blog/freelance-creation-site-web-maroc` (26.95), it sits above the page that keyword
belongs to. See [`_cannibalisation.md`](_cannibalisation.md).

**Its own topical query is its best ranking.** `comment choisir un développeur web freelance` at
**7.20** — page 1 — is exactly what the article is about. That is the post working correctly: a
distinct informational angle ranking well on its own terms.

**The unaccented variant ranks 16 places better than the accented one** — `developpeur web
freelance maroc` at 16.00 versus `développeur web freelance maroc` at 31.96, on the same keyword.
That pattern repeats across the site (`/developpeur-web-freelance-maroc` shows the same, 24.24 vs
35.58) and is worth treating as a general finding: **unaccented spellings consistently rank better
across this site**, probably because slugs and some copy are unaccented while Moroccan users search
both ways.

**Impressions up 4.5× while position fell 8** — the same broad-matching dilution seen on
`/developpeur-web-freelance-maroc` and `/about`. All three pages in cluster 1 show it
simultaneously, which suggests the cluster as a whole is being spread thinner rather than any one
page degrading.
